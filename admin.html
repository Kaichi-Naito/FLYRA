GitHub 接続

保存先：Kaichi-Naito / FLYRA · main
素材：assets/icons・assets/textures・assets/logos

初回の接続方法
  1. GitHubで Fine-grained token を作成
  2. Repository access は Only select repositories → FLYRA。
  3. Repository permissions の Contents を Read and write に設定。
  4. 発行したトークンを下の欄へ入力して接続。

トークンはこの画面を開いている間だけ使用します。GitHubやブラウザの保存領域には保存しません。チャットには送らないでください。
