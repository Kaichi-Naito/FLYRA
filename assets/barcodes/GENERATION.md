# Barcode sticker generation

Built-in image_gen tool. Three separate generated PNGs; all text is overlaid as editable project data. Runtime contours clip the generated artwork to sticker shapes.

## Inventory

Use case: stylized-concept. Asset: standalone printable cyberpunk Y2K barcode sticker for a poster editor. Wide rectangular industrial inventory label. Aspect 3:2. Thin doubled rounded rectangular silver border inset 5%. Main white dense vertical barcode across x8%-92%, y30%-62%. Blank dark text zones top x8%-92% y8%-26% and lower x8%-76% y69%-91%. Three tiny geometric recycling-like abstract icons lower right. Flat straight-on 2D scan, matte near-black charcoal paper with subtle photocopier grain and distressed scuffed white ink, authentic utilitarian technical packaging-label aesthetic. Sticker occupies almost all the canvas with a narrow transparent margin. Truly transparent outside die-cut label, no scene, no colored background, no shadows, no perspective. All reserved text zones must remain empty charcoal: NO letters, NO words, NO numbers anywhere. Barcode is decorative. Rich fine analog grain but crisp bars and clean silhouette. One sticker only.
