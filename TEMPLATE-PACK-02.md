# Template Pack 02

16 original editable compositions based on the user's supplied visual references. No reference image, logo, character or photograph is redistributed. Photo windows use procedural vector scenery as a placeholder. Select a photo window and choose 「ここに写真・商品画像を入れる」 to replace it. The arch, capsule, stair-step or wave mask is retained.

All headings, dates, venue, description and price remain text layers. Layout changes retain existing content, locked layers and user-added layers using the editor's existing behavior. Built-in system fonts keep initial thumbnails available offline; each text layer can use the expanded font library.
