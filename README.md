# FLYRA — 小さなデザインスタジオ

ライブのフライヤーとグッズのお品書きを作る、ブラウザ完結の静止画エディターです。JIZURA の「表現パーツを組み合わせて別案を試す」「気に入った部分をロックする」という考え方を参考に、新しく実装しました。

## はじめる

ZIP を解凍して `index.html` を Chrome / Edge で開くと使えます。インストール・ビルド・API キーは不要です。フォルダ内のファイルはまとめて置いてください。

GitHub Pages で公開する場合も、同じファイルをそのまま使用できます。

## 基本の流れ

1. 「デザイン」でテンプレートを選ぶ。
2. 「告知内容」にタイトル・日時・会場・出演者・料金を入力。欄の外をクリックすると反映。
3. 「素材棚」で質感やアイコンを複数選択し、まとめて追加。
4. キャンバスまたはレイヤー一覧で要素を選び、右側で調整。
5. 「書き出す」から PNG / JPEG を保存。「データ保存」は後で編集できる `.flyra` ファイル。

## 初版の機能

- 12種類のオリジナルテンプレート。リソグラフ風、紙・写真、Y2K、商品一覧など。
- おまかせで別案、配色だけ変更、配色を残した構図変更。ロックした要素と追加した画像・素材は保持。
- 文字・図形・画像の位置、サイズ、回転、不透明度、前後関係、複製、ロック、表示切替。
- 文字のフォント系統・太さ・行間・揃え・アウトライン・影・アーチ配置。長い文章は枠内に自動縮小。
- PNG / JPEG / WebP の追加・差し替え、ドラッグ＆ドロップ。トリミング、拡大、位置、明るさ、コントラスト、モノクロ。
- デュオトーン、二階調、ハーフトーン、スライス加工。四角・楕円・有機的な形・ダブル円・ひし形のマスク。
- 18種類の合成モード。通常、乗算、スクリーン、オーバーレイ、ソフトライト、ハードライト、ハードミックス、覆い焼きカラー、焼き込みカラー、比較（暗・明）、差の絶対値、除外、色相、彩度、カラー、輝度、加算。
- 素材棚：質感・グラデーション／アイコン・装飾／自分の素材。画像やフォルダを登録、複数選択で追加、自分の素材棚の保存・読み込み。
- 素材生成：グラデーション、メッシュ、粒子、フィルムグレイン、ハーフトーン。色・角度・密度・乱数パターンを変更。素材単体の透過 PNG 出力。
- SNS縦長・正方形・ストーリー・A5・A4。余白ガイド、中央揃え、ズーム、元に戻す・やり直す。
- PNG / JPEG 出力、背景透過、レイヤー単体出力（キャンバス全体の大きさ）、2倍解像度。
- ブラウザ内自動保存、編集データの保存・読込。素材と画像は `.flyra` に含まれます。

## 素材を増やす

アプリの「素材棚」で登録先フォルダを選び、「素材を登録」または「フォルダを登録」。画像はこのブラウザに保存され、GitHub にアップロードされません。「自分の素材」には登録したものが横断表示されます。

ブラウザのデータ削除・端末変更に備えて、「素材棚を保存」で JSON を保存してください。別の端末では「素材棚を開く」で追加できます。

同梱素材を増やしてアプリ自体を更新する場合：`assets/textures/` または `assets/icons/` に PNG を置き、`assets/manifest.json` に項目を追加して `node build-assets.cjs` を実行します。`assets/catalog.js` に画像を埋め込むため、ローカルで HTML を直接開いても書き出し可能です。

初版の画像生成素材は各3点、計6点です。プロンプトと生成方式は [assets/GENERATION.md](assets/GENERATION.md) に記録しています。

## GitHub Pages 公開

FLYRA は JIZURA と別のソフトです。独立した `FLYRA` リポジトリを作り、このフォルダの中身をリポジトリ直下に配置します。

1. 変更を `main` に反映。
2. リポジトリの **Settings → Pages** を開く。
3. Source を **Deploy from a branch**、Branch を **main**、フォルダを **/(root)** にして **Save**。
4. Pages の公開完了後、`https://kaichi-naito.github.io/FLYRA/` を開く。

これはリポジトリ作成・公開設定後の予定URLです。設定前にはアクセスできません。FLYRA のコード・素材・更新履歴・公開設定は独立して管理します。

参考：[GitHub Pages の公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 保存と制作上の範囲

- 初版は静止画の制作向けです。AI モデル学習、Photoshop/Illustrator ファイル読込、ペンツール、自動の人物背景除去、PDF/CMYK変換は含みません。
- 保存はブラウザ・URLごとです。ローカル版から公開版へ移るときは `.flyra` と素材棚 JSON を使って移してください。
- 画像は読み込み時に長辺2400px以内へ縮小します。原本は変更しません。1画像20MB、編集データ50MB、レイヤー150個、登録素材100点が上限です。
- 大きな画像を多数重ねたり、ハードミックスで高解像度出力すると処理が重くなります。出力は最大4,000万画素です。
- 印刷用サイズは300dpi相当のピクセル寸法です。出力はRGB画像で、DPIメタデータ・CMYK・塗り足し・トンボは設定しません。余白ガイドは安全マージンの目安です。
- フォントは端末にある書体を利用します。端末によって見た目が変わる場合があります。
- 公開版はアプリのファイルを配信しますが、入力画像・作品のデータをサーバーに送信しません。

## キーボード

Ctrl / ⌘ + Z：元に戻す、Ctrl / ⌘ + Shift + Z：やり直す、Ctrl / ⌘ + D：複製、Delete：削除。矢印：1px移動、Shift + 矢印：10px移動。右下ハンドル：拡大縮小、Shift：縦横比保持。画像は常に比率保持。Alt + ドラッグ：中央スナップなし。
